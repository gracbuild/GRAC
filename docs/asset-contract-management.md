### Rule semantics (421 -- the BRD is silent on these, so they are stated here)
- Conditions in one group are ANDed; groups are ORed. Operators: EQ, NEQ, IN, NOT_IN (`A|B` lists), EMPTY, NOT_EMPTY, GT, GTE, LT, LTE, DATE_BEFORE_TODAY, DATE_AFTER_TODAY, DATE_WITHIN_DAYS.
- A field with active SHOW rules is visible only while one of them is true; otherwise its static Visible flag applies.
- Mandatory = static flag OR any true REQUIRE rule, and never while hidden.
- Rules cannot target baseline fields, a field cannot drive itself, loops are refused on save and reported by readiness, and a field used by a rule cannot be removed.
- Option lists: the BRD-enumerated values only (40 lists, 201 values, global `reference_option` groups `asset_field.*`). Lists the BRD leaves to the organization (building, floor, room, zone, cost centre, network zone, domain, ...) stay empty and readiness warns until the organization adds values on the Option Lists screen (423).
